# Croissant — меню и заказы онлайн

Веб-приложение (PWA) для кофейни «Croissant — cakes and coffee»: гости смотрят меню, выбирают позиции с опциями и оформляют заказ. Сотрудники видят заказы и занятые столы в реальном времени.

Сценарии заказа:
- **В зале** — QR на столе открывает меню с номером стола, заказ попадает в раздел «Зал».
- **Доставка** — адрес, плата за доставку, минимальная сумма, бесплатно от суммы.
- **Самовывоз** — по желанию «ко времени».

Языки: русский и казахский. Оплата: наличные, карта на месте, Kaspi, онлайн.

## Структура

```
apps/api      Express 5 + TypeScript + PostgreSQL (чистый SQL), тесты vitest
apps/web      React 19 + Vite, роутинг, zustand, framer-motion
packages/shared  (зарезервировано под общие типы)
docs/         ТЗ, API, развёртывание
render.yaml   готовый сценарий для Render
```

## Быстрый старт (локально)

```bash
npm install
npm run dev:db -w apps/api     # встроенная PostgreSQL на порту 5433 (отдельный терминал)
npm run seed -w apps/api       # админ и демо-меню (admin / admin12345 по умолчанию)
npm run dev:api                # API на :4000
npm run dev:web                # сайт на :5173
```

Админка: `http://localhost:5173/admin`. Для продакшена скопируйте `apps/api/.env.example` и смените все секреты.

## Проверки

npm test          # 19 тестов API на настоящей PostgreSQL

## Что важно знать

- **WhatsApp.** После заказа гость нажимает кнопку, и готовый текст заказа открывается в WhatsApp заведения. Источник правды — раздел «Заказы» в админке. Автоматическая отправка требует WhatsApp Business API — это следующий этап.
- **Онлайн-оплата.** Сейчас работает демо-провайдер (`PAYMENT_PROVIDER=mock`) и ссылка Kaspi (`link`). Для реальных платежей нужен договор с эквайрингом (Kaspi Pay, Halyk, CloudPayments) и адаптер провайдера в `apps/api/src/services/payments.ts`. Вебхук с HMAC-подписью уже готов.
- **Меню** в seed — демонстрационное. Реальные позиции вносятся в админке («Меню»).
- **Логотип** в `apps/web/src/components/Logo.tsx` перерисован как SVG; замените файлом из брендбука.
- Подробности: `docs/TZ.md`, `docs/api.md`, `docs/deploy.md`.
