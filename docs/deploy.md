# Развёртывание

Приложение — один Node-сервис: API и собранный сайт отдаются с одного адреса. Нужна PostgreSQL.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `NODE_ENV=production` | включает обязательные секреты и SSL к БД |
| `DATABASE_URL` | строка подключения PostgreSQL |
| `JWT_SECRET` | длинная случайная строка |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | первый администратор (создаётся автоматически при первом запуске) |
| `PUBLIC_URL` | адрес сайта, например `https://menu.example.kz` (идёт в QR-коды) |
| `CORS_ORIGIN` | тот же адрес |
| `PAYMENT_PROVIDER` | `mock` для теста, `link` для ссылки Kaspi |
| `PAYMENT_WEBHOOK_SECRET` | секрет подписи вебхука оплаты |

## Render

1. Загрузите репозиторий на GitHub.
2. В Render: New → Blueprint, укажите репозиторий. `render.yaml` создаст веб-сервис и базу.
3. Задайте `ADMIN_PASSWORD` и `PUBLIC_URL`, дождитесь деплоя.
4. Администратор создаётся автоматически при первом запуске из `ADMIN_USERNAME` / `ADMIN_PASSWORD`. Демо-меню (`npm run seed`) на продакшене не запускайте.

## Зависнет ли Render?

Бесплатный тариф засыпает после ~15 минут без запросов, и первый гость ждёт около минуты пока сервис проснётся; бесплатная база Render также ограничена по сроку. Для рабочего заведения берите платный веб-сервис (Starter) и платную базу, либо VPS (например 2 vCPU / 2 ГБ) с Docker и Caddy/nginx. Актуальные цены уточняйте на сайтах провайдеров.

## Перед открытием для гостей

- Смените все секреты и пароль администратора.
- Укажите номер WhatsApp в «Настройки».
- Внесите настоящее меню и часы работы.
- Распечатайте QR из «Столы и QR» (после того, как задан итоговый `PUBLIC_URL`).
- Сделайте тестовый заказ с телефона.
- Настройте резервные копии базы.
